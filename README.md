# ScalpGuard AI 🔬

An AI-powered scalp analysis web app built with React + Firebase + Google Gemini.

## Features
- 🤖 AI scalp diagnosis 
- 💬 Hair Doctor chatbot powered by Gemini AI
- 🛒 Product recommendations 
- 📊 Scan history with trend charts
- 🔐 Firebase Authentication

## Tech Stack
React · Vite · Firebase · Tailwind CSS · TensorFlow.js

## Setup
1. Clone the repo
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your API keys
4. Run `npm run dev`
